# Arco v0.1.0 release notes

These notes describe the first public Arco release, `v0.1.0`.

## Arco

Arco is a local software workbench for project-aware conversations with provider-backed agents. It brings chat, project folders, terminals, files, Git, saved work, clusters, review tools and optional voice into one browser interface. Providers and model accounts are configured separately; Arco does not bundle an AI model or account credentials.

## Platforms and installation

Native installation targets Linux, macOS and Windows. Current package
installation instructions are in the [README](../../README.md).

`arco setup` asks before installing the per-user service, starts it, and opens
the local URL. The [README](../../README.md) covers foreground operation,
service management, platform troubleshooting, Docker, and source builds for
contributors.

A Docker image provides an isolated server with a persistent Arco home and explicitly mounted project folders. Fetch tags and check out the newest stable release; replace `vX.Y.Z` with the chosen tag. Copy `.env.example` to `.env`, create the sample project mount, and run:

```sh
git fetch --tags origin
git tag --list "v*" --sort=-v:refname
git checkout --detach vX.Y.Z
cp .env.example .env
mkdir projects
docker compose up -d --build
```

The [Docker guide](../DOCKER.md) covers Windows path setup and other mount options. The [Getting started guide](../GETTING_STARTED.md) walks through connecting a provider, choosing a project and starting a conversation. For updates after install, see [Updating Arco](../OPERATIONS.md#updating-arco).

A new native installation with no projects or connected providers opens Welcome to Arco. The setup adds a project folder, connects a provider through Connections, then offers Go to Home or Start a chat. Each earlier step can be skipped, and setup can be reopened from Settings. Docker users sign in to a provider from inside the container and use mounted project folders.

## Providers and features

Generally available provider integrations include Claude, Codex, Cursor, Ollama, LM Studio and llama.cpp. Optional external-service integrations include Strata and DeepSeek through Xolotl; their services must be installed separately and are not distributed by Arco. Account access, installed command-line tools, model availability, billing and local service configuration vary by provider. The [provider guide](../PROVIDERS.md) lists transport and feature boundaries.

The workbench includes Project Home, saved and Incognito conversations, an embedded terminal, a Git workbench, Preview, Review, Compare, Research, Handoff, Spawn, clusters, plans and an in-app manual. The operator chooses providers, models, tools and whether to enable automation. See the [feature reference](../FEATURES.md) and [operator actions](../OPERATOR_ACTIONS.md).

Optional GitHub release notices appear as an in-app toast (**OPEN RELEASE** /
**DISMISS**) with Settings > Advanced **CHECK NOW** and an opt-out. Packaged
installs use `arco update`, which installs the latest stable package with a
snapshot for rollback. Packaged services offer **UPDATE AND RESTART** on Linux,
macOS and Windows. Source checkouts retain `npm run arco:update`. See
[Arco release notices](../SETTINGS.md#arco-release-notices).

Native voice setup is available through `arco voice setup` for package users
and `npm run voice:setup` in a source checkout. It requires `uv` and downloads
Moonshine and Vosk recognition models, Parakeet on supported platforms, and
Kokoro speech voices on request. Licenses, versions, hashes and source URLs are
written to `NOTICES.md` in the voice home. The downloads are not redistributed.
The Docker image lacks the speech runtime. Parakeet is skipped on Windows,
where Moonshine remains the English recognizer. See
[Voice and Computer](../VOICE.md) and [third-party notices](../THIRD_PARTY.md).

## Documentation

The reference documentation is written for public readers. Strata and DeepSeek through Xolotl are framed as optional external services that Arco does not distribute. Contributor recipes live in [Extending Arco](../EXTENDING.md), with troubleshooting and hot-reload guidance in [Diagnostics](../DIAGNOSTICS.md).

## Known limits

- Native Linux and Docker passed README-only fresh-install acceptance. macOS and Windows rely on automated checks (hosted CI) for this release; physical-host acceptance remains open. Three-OS CI is green.
- The Vosk English model uses its official versioned download URL and a pinned SHA-256. The publisher does not provide a revision-addressed asset URL, so the URL itself is not immutable; a changed response fails checksum verification before extraction.
- The Moonshine, Kokoro and Parakeet archives are fetched through the unauthenticated GitHub API, which has a 60-request-per-hour limit per IP address. Voice setup requests three such assets; repeated installations may be rate-limited. Each archive is still checked against its pinned SHA-256.
